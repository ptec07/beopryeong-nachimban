# 법령나침반

법령명을 몰라도 내 상황을 입력하면 관련 법령, 처분기준, 판례, 행정심판례를 근거와 함께 찾아주는 자연어 법령 리서치 웹앱입니다.

## MVP scope

- 자연어 질문 입력
- 반구조화 질문 라우팅
- 근거 기반 답변 카드
- 행정처분/임대차/계약서 beta 흐름
- fixture-backed backend for TDD before real legal data integration
